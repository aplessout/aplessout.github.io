IPTV · Roku validator

Tests a Media Assistant launch URL against your Roku.

Target

Launch URL

—

Definitive check (desktop)

A browser cannot read the Roku's reply because it sends no CORS headers. curl can:

—
  • HTTP 200 — the Roku accepted the launch; the TV should switch to Media Assistant.
  • HTTP 404 — the request arrived, but as a GET. The launch endpoint is POST-only.
  • Connection refused / timeout — wrong IP, wrong port, or Control by mobile apps is disabled.

Why this page must run locally

  • An https:// page cannot reach http:// LAN devices — browsers block it as mixed content. This includes this page when served from GitHub Pages.
  • Save this file, open the saved copy from disk (or serve it over http://), and the request is allowed.
  • The response is still opaque either way: Roku sends no Access-Control-Allow-Origin, so only curl can read a status code.
  • Roku needs Settings → System → Advanced system settings → Control by mobile apps → Network access: Enabled.
